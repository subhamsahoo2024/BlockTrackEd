This is a BlockChain based scholarship tracking system

To set the environment
-clone the repository
-open terminal
-type npm install

To run the project
-open terminal
-type npm run dev

The solidity contract in given in contract folder for verification

This project used sepolia net instead of Etherium main-net.

The contract can be runned using remix ide and new contract address can be passed in CONTRACT_ADDRESS variable in src/contexts/Web3Context.tsx file
